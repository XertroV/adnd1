# Rules and fighter matrix mechanics review

All 149 assembled records (148 rules and one matrix) have been reviewed against rendered PHB, UA and DMG pages. The companion `research/mechanics-rules.json` lists 751 checked JSON paths with source file hashes and printed/PDF page mappings. It separately identifies 24 `reviewedPaths` as editorial advice, interpretation or review-status guidance rather than independent numerical or mechanical claims. The earlier remaining-path list has been reviewed; no paths remain marked merely unaudited. This scope does not cover fields outside those paths, other sources, or all possible interpretations.

The DMG page 74 fighter attack matrix was rendered at high resolution and all 210 cells read. Its existing 70 populated cells agree with the printed table; 140 proposed changes fill formerly null cells, and one updates the now-obsolete partial-transcription note. The matrix's rule notes and numerical comparison examples were also checked against printed pages 70, 74 and 82. These changes are proposals for independent review, not application data edits. A further proposal narrows the aerial travel conversion on DMG page 50 to flying carpets or similar magical devices, the scope stated by the source.

Page 175 is absent from the supplied DMG scan. The existence or status of a numbered page 240 remains unverified. No app data has been changed.
