# Unearthed Arcana spell mechanics review

All 224 UA spell records have at least some existing mechanics paths compared with rendered spell descriptions and, where cited by reviewed statements, underwater-use notes. Class and level metadata, existing fields, and source-local effects, conditions and exceptions are individually recorded as JSON pointer paths in the proposal file. The `/classes` path is checked for magic-user cantrips where the UA p.65 introduction explicitly grants illusionists access. The 119 corrections and OCR-note changes passed independent review and have been applied.

Three existing paths identify source ambiguities requiring adjudication: Melf's Acid Arrow duration, Invisibility to Undead recipient, and Ceremony rank wording. The path count does not establish complete coverage of omitted mechanics or all underlying comparisons. Many spells refer to other spells, items or monsters; selected cross-references were inspected, but others still require separate review. Withdraw also retains a source formula/example conflict, and Zephyr retains an ambiguous pin-material phrase. Original-source contradictions are not resolved by treating one conflicting passage as authoritative. No record is claimed fully audited. Full-page source images remain private.
