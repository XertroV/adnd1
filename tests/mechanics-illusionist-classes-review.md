# Illusionist spell and class mechanics review

The accompanying `research/mechanics-illusionist-classes.json` covers the existing tracked fields of 66 PHB illusionist spells, 16 class guides, and the progression explainer. A checked path identifies only the assertion visually compared with the cited original PDF pages; it does not certify every rule in a passage or claim the cards contain every possible rule. Editorial classifications identify labels, empty lists, or advice and are not source-verification claims. Corrections remain proposals requiring independent review.

The spell review included the PHB illusionist headers and the relevant spell passages and inherited effects. Proposed corrections include printed dimensions and ranges, the Magic Mouth trigger, and Astral Spell's caster reference. Light and Continual Light print “Saving Throw: None” in their illusionist headers while their inherited text describes target saves. Emotion/Symbol and the PHB p.94 versus p.100 magic-user spell-list questions remain unresolved. Shadow Magic and Demi-Shadow Magic print “Special” for duration and area; four proposals restore that header wording and direct readers to the spell descriptions.

Class review covered the listed XP thresholds and continuations, prerequisites and existing level-change assertions against their cited PHB, DMG and UA pages, including spell slots, thief skill progressions, monk abilities, bard advancement and UA subclass changes. Missing XP thresholds and selected level changes are proposed in complete replacement arrays for reviewer inspection, preserving existing metadata where applicable. The UA cavalier continuation has a proposed 900,001 XP anchor; the UA druid proposal preserves the separate Hierophant reset. The magic-user replacement includes the PHB p.26 levels 13–15. Cross-book or printed ambiguities remain explicitly recorded, including monk attack tables, UA cavalier hit dice, UA paladin attacks, the barbarian's printed attacks and thief-acrobat retained skills. The progression explainer's tracked source assertions and editorial wording were reviewed separately.

In change entries, `oldValue: null` indicates an absent object key and `newValue: null` means removal of an existing array member, not a literal null value. Array replacements and deletions require checking the complete parent array and exact old values before applying. SHA-256 values identify the locally supplied source PDFs; full PDFs remain private. No application data was changed by this review.
