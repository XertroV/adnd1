# Local source reader

`FirstEditionSourceViewer.open({item, references, contextItemId, initialReference})` accepts grouped references:

```js
[{book: 'PHB', pages: [35, 37, 38], labels: ['Weapon tables']}]
```

Optional `contexts: [{page, label}]` supplies page-specific labels from the citation collector. `item.name` or `item.title` supplies the modal subtitle. The existing `FirstEditionBooks` module supplies printed-page mappings. PHB, original UA, revised December 1979 DMG, Monster Manual and Monster Manual II are supported. The DMG's printed p.175 remains absent from its supplied PDF; a separate user-confirmed correct-edition image is usable as source evidence through two limited excerpts. The full image is not part of the PDF or published. Pages 239–240 display unverified end matter; MM2's misplaced printed p.83 maps to PDF p.92, printed pp.84–91 map to the same PDF page number, and printed pp.92–160 resume the +1 offset. Neither manual is hosted.

Callers pass the actual card as `item` and its real ID as `contextItemId`, while `references` contains the full citation list for that owning entry. Header and inline links pass `initialReference: {book, page}` to select the clicked citation without filtering the list. A grouped citation starts at its first printed page; the all-scans button and unmatched initial references start at the first available list entry. All explicitly supplied IDs (`item.id`, `contextItemId`, and optional `item.contextItemId`) must agree. Per-item excerpts require `item.scanVerification.state === 'selected-values-checked'` and a catalog path matching `^scans/dagger/(manifest|(?:phb|ua)-[a-z0-9-]+)\.json$`. Absolute paths, external URLs, traversal, encoded path variants, queries, and fragments do not enable excerpts. The catalog's `itemId` must exactly match that actual item. The existing no-metadata `phb-dagger` fixture path retains its legacy manifest fallback; an explicit unchecked or incomplete metadata object does not use that fallback.

Load `source-viewer.css` and deferred `source-viewer.js` after `books.js` and before callers. The viewer creates a native modal on first use. PDF.js is imported only after a user selects a local file. Full PDF bytes enter PDF.js through `File.arrayBuffer()` and its `data` option. No PDF URL, upload, external CDN, Library identifier, local-storage PDF, or full source document is included. A loaded document remains in tab memory until Forget, replacement, or refresh. File names and lengths do not establish book identity; the interface asks readers to match the stated edition and page order. Too-short PDFs are rejected because they cannot satisfy that mapping.

PDF.js is pinned to official `pdfjs-dist@6.5.438`; `dist/vendor/pdfjs/version.json` records the registry URL and integrity. Minified legacy display/worker/renderer files and the package's bundled CMaps, standard fonts, WASM, ICC assets, and their licenses are vendored for same-origin use. The renderer module is included for compatibility but is not enabled as a separate renderer worker. PDF scripting and XFA are not enabled by the reader. Module usage follows [Mozilla's example](https://mozilla.github.io/pdf.js/examples/) and [API documentation](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html).

Run `node tests/source-viewer.browser.mjs` with Playwright and Chromium installed. It makes original text-only PDF fixtures in `/tmp`, serves only the public renderer files and a test harness, and checks printed/PDF mapping, the DMG gap and unverified end matter, invalid and too-short files, zoom, touch and keyboard navigation, modal focus/Escape, mobile widths, document forgetting, and network requests. Screenshots and fixtures stay in that temporary directory for review. These fixtures test the reader; they do not verify any AD&D wording, page content, or scan region.

The dagger entry (`phb-dagger`) offers seven approved excerpt regions from PHB printed pages 35, 37, and 38 and UA printed page 28. This local batch-2 implementation also permits audited, explicitly configured per-weapon catalogs to select other checked context rows within those same seven unchanged PNG files. It introduces no new source images or full PDF files. The renderer validates the image allowlist, exact printed/PDF page mappings, region IDs, dimensions, fingerprints and verification markers, and normalized focus rectangles. Only each catalog's explicitly selected values and notes have been checked; surrounding rows, full pages, other equipment, and entire books do not inherit that verification.

Catalog promises are cached by their full same-origin URL. Every opening independently validates the catalog's exact item ID before applying it. Images are cached by full URL, with dimensions rechecked for each region and per-item captions, alt text, checked fields, and focus overlays rebuilt from the current catalog. Shared image bytes do not share row verification. Separate session, catalog-request, and render guards prevent late item-A success or failure from replacing item B or the chosen private-PDF mode. A queued Close from an earlier opening does not cancel a newly opened item. Field citations retain their exact page subset: dagger UA page 28 remains two UA regions, and an unrelated entry citing that same page remains local-PDF-only without its own checked catalog metadata.

Excerpt mode uses same-origin public assets, readable table sizing, fit-width and actual-size controls, zoom through 400%, and keyboard/touch panning. The local-PDF mode keeps the earlier private-file behavior. Catalog and image failures have bounded loading deadlines, show the local-PDF fallback, and expose an explicit retry button. Source PDF fingerprints are labelled as supplied with the handoff; the PNG fingerprints were computed for the reviewed crop files. No source PDF was transferred or hosted by this integration.

Narrow images (up to 640 pixels wide) fit the available width by default so the price column remains visible on mobile. Wide tables retain a readable initial width and horizontal pan. Pages with only one excerpt hide the redundant region selector while retaining the highlight toggle and accessible caption; PHB page 38 and UA page 28 retain their multi-region selectors.

Run `node tests/dagger-source-viewer.browser.mjs` to preserve all seven dagger-image checks, normalized rectangle geometry, four cited pages and their 1/1/3/2 excerpt choices, exact UA field scoping, unchecked-entry exclusions, desktop and 491/390/320-pixel layouts, image zoom/panning, modal focus, local-PDF switching, catalog/image failures with explicit retries, and late-manifest races.

Run `node tests/batch2-source-viewer.browser.mjs` for actual assembled checked-item catalogs plus the metadata/cache/race matrix. Its `--fixtures-only` option tests HTTP-only synthetic catalogs when audited data assembly is still pending; these fixtures never write public verification data. It covers checked-state/path/ID gating, mismatched catalogs, same-image independent row focus, dimension checks on cached images, per-URL caches, A/B and Close/reopen races, stale image failures, private-mode choice, and explicit retry. The default additionally requires all eight checked entries to be assembled and exercises every actual region. These are local-only batch-2 changes under the publication hold; running tests does not publish them. Entries without checked catalog metadata retain the private-PDF reader and no verified-excerpt mode.

The compact header combines the dialog and entry titles and keeps the mode switch immediately before Close, wrapping the header when necessary. The source-notice dismiss button hides that notice across modal openings until reload, without persistent storage. Dismissal removes the dialog description reference and moves keyboard focus to a visible control. Desktop/mobile browser regression coverage is in `source-viewer-header.browser.mjs`; that browser check was added but not executed in the managed environment without its required browser interface.
