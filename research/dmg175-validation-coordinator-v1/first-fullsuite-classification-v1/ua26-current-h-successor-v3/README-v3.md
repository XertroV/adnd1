# UA26 Caltrop pairing correction — V3 research proposal

V3 fixes the one remaining failure in the root-installed V2 focused run. The V2 marker CLI and helper passed their native-H checks; `tests/ua26-catalog-context.test.mjs` failed because its `bytes()` helper intentionally calls `readBeforeJoFile`, which returns the frozen pre-Jo Caltrop catalog for the registered history scope. The test then compared those historical bytes to the live Jo-extended hash.

The minimal proposal changes only that Caltrop assertion. It checks the projected bytes against `extension.before.uncompressedSha256`, reads the installed catalog directly with `fs.readFileSync` and checks that byte stream against `extension.after.sha256`, then checks and returns the decompressed frozen checkpoint as before. All historical catalog parsing continues to use the projected pre-Jo checkpoint. The UA28 catalog-transition set and its fourth-transition negative control are untouched.

V2's staged 17/17 result did not exercise the production-root projection. Its staging script symlinked `tests/helpers/ua-source-batch6-jo-fixture.mjs`. Node resolved the helper module to the production checkout, but the copied test passed it an absolute path under the temporary stage. `readBeforeJoFile` computed a relative path outside its scoped-history list and fell through to raw file reads. In the real checkout, both the helper and test paths are under the production root, so the helper projects Caltrop to the pre-Jo checkpoint. V3's baseline replay copies that history helper into the stage so the helper and test share a root; it reproduces the installed failure with actual `f0eb5c844829ed7eceaabe4c419bb29a58b8b49e0efbac6de648d3502f6d0379` versus expected live `d1888665bc90d8cf3b2dd226cfa67a27295a9d10da3c6c67313810b5bd5331fb`.

After applying the V3 test patch in that faithful root layout, all 17 focused assertions pass, including the installed H helper and CLI positives, source identity and stale-epoch negatives, all marker and note-association preservation checks, and the fourth catalog-transition hard failure. The probe log and machine-readable report are `after-focused-probes-v3.log` and `validation/root-layout-probes-v3.json`; the unpatched reproduction is `before-projection-reproduction-v3.log`.

This proposal changes no source catalog values, marker inputs, receipts, grades, helper contracts, manifests, seals, Git metadata, or workflow. The V1 and V2 proposal lanes remain frozen. This V3 patch is only for `tests/ua26-catalog-context.test.mjs`; the V2 workflow CLI retarget and native-H successor candidate remain as previously reviewed.
