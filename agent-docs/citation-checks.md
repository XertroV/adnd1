# Deterministic citation checks

Read [Citation images and verification](citation-images-and-verification.md) first. Automated checks generate candidates or enforce recorded contracts; they cannot establish contextual adequacy or whole-book correctness.

## Offline source-price page discovery

`python tools/source-price-page-discovery.py --source-dir /path/to/private/books --output-dir /tmp/adnd-source-price-discovery-run` scans all pages of the five local PHB, DMG, UA, MM and MM2 PDFs for broad currency, transaction and valuation text cues. PyMuPDF is required for this command; its cue fixtures run with Python's standard library only. Choose a new output directory outside the repository. The tool does not copy PDFs or replace any manual census/review artifact. Its page records, line bounds and candidate queue are discovery-only: empty OCR and no-cue pages are not absence passes, and no value or semantic category is automatically confirmed.

## Implemented now

1. `research/source-visual-audit.py` reads the authorized original PDFs with PyMuPDF. It maps every current catalog crop to PDF points, verifies source/image identities, and finds text-layer word boxes that cross each crop boundary. The public output contains numeric bounds and identifiers, not source text or PDFs.
2. `research/crop_geometry.py` supplies the exact boundary-intersection function used by both the offline auditor and CI fixtures. `tests/crop-geometry-fixtures.py`, invoked by the Node test suite, calibrates old versus repaired Animate Object bounds against three original numeric word boxes. It tests all four edges, exact touching, corner intersections, unrelated neighbors, and missing-text-layer limitations. CI needs only Python's standard library for these fixtures, not the private PDFs or PyMuPDF.
3. `tools/source-visual-coverage.mjs` consumes the checked-in release geometry snapshot, falling back to the historical corrected snapshot. It verifies current catalog/source/image hashes before applying candidates. It reports stale candidates when evidence changes. Exact full-image highlights are suspected unless independently excepted. Hash-bound manual assessments keep crop completeness, contextual adequacy, highlight relevance and default selection separate.
4. Existing public scan tests check catalog/image consistency and assembled citation counts. Viewer browser tests cover source permalinks, copy, history and focus. These tests do not verify the meanings of source passages.

Regenerate geometry locally after assembling changed catalogs:

```sh
python research/source-visual-audit.py --source-dir /path/to/authorized/books --output-prefix release
node tools/source-visual-coverage.mjs
node --test tests/*.test.mjs
```

The source directory must contain the five filenames declared in the auditor. Do not upload that directory. Commit the numeric release snapshot and its queues after review; preserve historical baseline/corrected snapshots. CI regenerates the public coverage JSON/Markdown and uploads `source-visual-coverage` without needing the books.

## False positives, false negatives and review

- A word box crossing an edge can be an unrelated neighboring row, a column fragment, or misaligned OCR. It remains a candidate until the actual pixels and source context are checked.
- A boundary merely touching a word box is not an intersection. This numerical convention is not a guarantee that rasterized ink is intact.
- Missing or inaccurate OCR can miss clipped letters. A source fold can destroy letters before cropping. Image margins or a zero-candidate result cannot prove completeness.
- Whole tables can be legible yet contextually inadequate when headings, units, footnotes, wrapped rows or continuations are absent. Small crop size alone is not a semantic verdict.
- Resolve candidates per current binding. Record the exact source/image/rectangle hashes, scope and evidence. Keep confirmed defects, rejected heuristics, explicit exceptions and unreviewed work distinguishable. Retain superseded wrong reviews, as with Animate Object.

## Implemented contracts and inventories

- **Entire exposed data tree:** `tools/citation-systemic-inventory.mjs --output-dir /tmp/adnd-systemic` enumerates all content records, JSON pointers, scalar properties, structured references, monetary candidates and catalog usages. Its pinned pre-repair baseline is `research/citation-systemic-baseline.json`. Structural validation rejects invalid owners, pages, region IDs, stale hashes and malformed bindings. Source support, completeness, relevance, qualifiers and unannotated continuations remain explicit unresolved dimensions for every applicable property; a clean structural report does not certify them.
- **Price reconciliation:** `tools/price-source-inventory.mjs`, called by assembly, joins independently enumerated source rows to current extracted objects through a hash-bound review overlay. `research/price-source-inventory.json` includes object/value/quantity, source and row identity, field binding, crop and highlight coordinates, review grades and unresolved claims. The named-table denominator is separate from the five-book page-discovery census. Untranscribed tables and unreviewed/no-cue pages remain discovery work, not completeness passes.
- **Source-table citations:** `node tools/source-table-citation-coverage.mjs /tmp/table-citations.json --check` reconciles every bounded monetary source row and explicit non-price table contract against all exposed records. It retains aliases as candidates and requires an explicit reviewed row/item mapping before declaring a missing citation. Variants, inapplicable mappings, absent references, absent excerpts and wrong source identities have separate dispositions. Required region IDs prevent another table on the same page from satisfying a declared table obligation. The original Harpoon/UA28 omission is pinned to Git in the regression tests. Catalog table candidates and untranscribed discovery groups remain explicit unknown row denominators; page presence does not certify context or fact highlighting. CI publishes the `source-table-citation-coverage` artifact.
- **Context extent and qualifiers:** `tools/citation-context-contract.mjs` checks manually annotated required table extents and evidence dependencies. Git-backed fixtures retain the bad Arrow/Long Sword/Aklys row crops, omitted PHB19/37 notes and a failed intermediate crop. Required-extent containment is valid only for its recorded source and annotation; it does not infer the correct extent of unannotated tables.
- **Continuation order:** `tools/continuation-contract.mjs` checks explicit required segments and source identity for known passages. `tools/continuation-order-audit.mjs` additionally compares the actual catalog sequence and the untargeted same-page viewer sequence, including the viewer's stable context-last sort. Run `node tools/continuation-order-audit.mjs --output /tmp/continuation-order.json` for every declared group. Unrelated regions may interleave, but required segments must retain their relative order; duplicate required IDs are defects. Multi-page viewer navigation order, unrelated-region defaults and field-target overrides are separate obligations. Charging continues from the left to the right column on DMG66; the original report's page67 hypothesis was disproved by source review. Abjure's two UA37 segments and the complete Animate Object image remain regression checks. Unknown column/page continuations remain unresolved.
- **Preserved ordering false pass:** the validator at commit `461b74f` searched by region ID and accepted a reversed Abjure catalog. `research/citation-continuation-order-baseline.json` preserves that result and the complete 14-group/28-segment census before the contract repair. All 14 current groups already had the correct catalog/viewer order and opening default; this was a validation defect. The order regression fixture retains metadata, not scan pixels. A manifest pass does not discover missing continuations or prove semantic completeness.
- **Published linked passages:** assembly validates the source manifest before writing the whitelisted `dist/source-continuations.json` projection. It publishes only declared owner/catalog/segment joins and identities, not private PDFs or review notes. The viewer must recheck those joins against its loaded catalog, preserve the selected part's exact URL and show each part's own source location and highlight state. Showing parts together does not approve fact relevance or override pending field targets. `research/source-viewer-navigation-baseline.json` preserves the preceding page-only controls and Abjure's separately selected excerpts. Cross-page mechanism fixtures are synthetic unless a real source-reviewed passage is explicitly identified; unknown continuations remain review work.
- **Navigation and rendered controls:** `tools/citation-navigation-coverage.mjs` inventories source-link producers and URL parameters. `tools/citation-browser-inventory.mjs` and the browser inventory runner enumerate rendered citation controls across every exposed route, including filter/progression states. Tests cover field identity versus displayed source owner, exact links, copy, reload, Back/Forward, search selection and filtered direct routes. They validate transport and target selection, not the meaning of a cited fact.
- **Viewport and review warnings:** browser fixtures distinguish stage scrolling from image cropping, test Fireball/Sleep framing, and exercise warning visibility. An exact `[0,0,1,1]` sentinel remains unresolved unless a current independent review explicitly has both `scope: whole-spell` and `kind: whole-spell-unmarked`. Such an exception never waives precise highlighting for an individual fact. A mixed sentinel and precise focus still warns.
- **Shared images:** `tools/assassin-shared-image-inventory.mjs` compares the pinned baseline and current catalog/source-reference universe before replacing shared excerpt images. Its consumer dispositions distinguish the same passage, unrelated table rows and uncertain class applicability. Sharing pixels does not transfer a semantic review grade.

CI always attempts both the systemic inventory and visual coverage report, uploads their full JSON/Markdown artifacts, and retains generator failures as failures. The reports distinguish structural validation from manual/contextual work. Private-source geometry regeneration remains an offline step; CI validates the recorded hashes and calibrated fixtures.

## Monetary and owner audit checks

`node tools/quantity-source-absence-audit.mjs --output-dir artifacts/quantity-source-absence --check` walks every scalar property in the current distribution and all nine monetary inputs. It preserves the before cases and records uncertainty text, source-absence assertions, newly detected lexical candidates, and null quantity metadata separately. The CI artifact is a review queue: a missing phrase, removed assertion, or null value never establishes that a printed source omits a quantity. Current counts and input hashes come from the current tree; frozen calibration counts remain historical.

`node tools/monetary-unit-provenance-audit.mjs --output-dir artifacts/monetary-unit-provenance --check` inventories unit, quantity, interval and source-basis properties across those inputs. Its classifications distinguish printed units, editorial wording, missing provenance and unassessable metadata. The preserved Whale example tests an unsupported per-lump unit against the original source and exact earlier inputs. Clearing that unit to null does not establish a source-absence rule or a replacement unit; the printed carcass rate is a separate positive control.

`node tools/ua-source-context-obligations-cli.mjs --check` checks the complete declared UA price-row/context universe against its frozen baseline. Primary table crops, row focus, source frames, note definitions and row-to-note joins are separate objects. A structurally resolved join does not establish that the note applies to the row. Independent source review must record that meaning, including ambiguous marks and unavailable readings. CI uploads the complete obligation inventory as `ua-source-context-obligations`.

The UA p.10 calibration fixture retains all source text-layer boxes without OCR strings and the five original failing crop bounds. The Python geometry test verifies the original edge candidates and the proposed bounds. These geometric checks do not clear source-inherent fold damage or establish semantic context or precise highlights.

`tools/monetary-row-identity-audit.mjs --check` inventories the declared monetary source surfaces, preserves duplicate-focus and source-confirmed failures, and requires exact current independent dispositions for known findings. Crop, focus, annotation, typed-content and source-scope findings have separate checks. Correcting an overclaim to an explicitly uncertain representation does not resolve the underlying source question. Duplicate locators are separate from duplicate highlights; neither is automatically a semantic defect. CI publishes the full `monetary-row-identity` artifact.

`tools/monetary-findings-register.mjs --check` requires the active finding manifest to retain every sealed monetary finding extension and uncertainty register. Keeping an old evidence file while dropping its reference cannot shrink the checked universe. New finding extensions must be added to the evidence seals before a repair is integrated. Register membership and byte integrity do not establish a successful source repair.

Fingerprint migrations retain pending findings. A migration's complete before projection must be derived again from the immutable source archives; internally consistent hashes supplied by the migration itself are insufficient. Physical crop windows exclude cosmetic labels, status wording and rendering-only changes. A changed window or focus is necessary for the relevant geometric repair, but still requires independent review of its actual pixels and source meaning.

Ordered source parts need their own source and render frames. A secondary passage must not inherit a different primary row's DPI. `tools/monetary-source-render-frames.mjs` checks a measured frame registry against the complete book, printed/PDF page, source PDF hash, render hash and dimensions. The registry records 22 independently reproduced PHB/DMG frames, including their MediaBox or CropBox mode and PDF geometry. Filenames do not establish DPI. Explicit frame declarations must agree; an unknown secondary frame without a DPI declaration remains unassessable. Registry lookup establishes frame provenance only, not source meaning or completeness. Imported helper and registry evidence hashes belong in the adapter's dependency pins and current index validation artifacts.

`node tools/monetary-coverage-report.mjs` joins every indexed source occurrence and value claim to the current row audit using exact input path, byte hash and row pointer. Its CI artifact includes the price inventory and row audit. It retains upstream transcription states and current finding dispositions separately, exposes missing joins, and links each claim to its object, value, citation and coordinate evidence. Neither a successful join nor a repaired finding certifies an otherwise unreviewed row.

`node tools/monetary-group-focus-audit.mjs --check` inventories every authored focus declaration in the PHB/DMG supplement and compares grouped copies with their exact primary rows. It distinguishes metadata differences, physical geometry differences and unsupported declarations. Matching copies can both select the wrong printed row; their independent source reviews remain separate.

`node tools/monetary-condition-coverage.mjs --output artifacts/monetary-condition-coverage/report.json` checks the current monetary index, joins it with the live row audit, and inventories explicit condition and qualifier fields. The four declared sage-information contracts retain their frozen failures separately from current finding dispositions. Contract binding requires the exact source path, hash, row pointer and audit identity. A changed, deleted or null condition does not clear a source contract, and an empty field does not establish that the source has no qualification. Historical capture is explicit and refuses to overwrite existing evidence.

`tools/source-target-label-audit.mjs --current --check --output-dir artifacts/citation-target-labels` inventories field captions across the current collected target universe. Array indices must have a readable context and must not be presented as character levels. The frozen before/after replay calibrates the original numeric-only caption failures; nonnumeric labels still need semantic review. This check does not establish that a target is rendered in every UI state or that its source evidence is correct.

The optional offline source-word witness inventories supported and unsupported coordinate frames and flags missing expected numbers or foreign row labels. Its frozen before snapshot includes known failures, including shifted assassination-fee and poison rows. Word boxes and a negative result do not establish correct pixels, wrapped lines, complete footnotes or source meaning. Retained positive manual assessments must be checked against their exact recorded overlays; a readable source crop or correct transcription cannot approve a highlight.

`tools/source-owner-identity-audit.mjs --check --replay` checks collection-qualified citation ownership, shared reference objects and unresolved active bare-key overrides. Equipment price-state and class progression overrides keep their declared collection scope. CI publishes the current owner audit. Historical capture claims and any unreproduced evidence are recorded separately from the current validated report; do not silently rewrite a sealed baseline or describe a later serialization as the original bytes.

## Raster boundaries and remaining detector gaps

The offline `research/source-raster-boundary-audit.py` inventories connected components in narrow source-pixel bands at every declared crop edge. Its preserved before snapshot covers all 3,069 catalog uses, 1,284 image geometries, 1,015 catalogs and 229 available source pages in that captured tree. Weak ink, components crossing an edge, and nearby components entirely outside an edge remain separate candidates. The five real-source calibration cases retain three clipped heading prefixes and two corrected-bottom controls. Components can be rules, illustrations, neighboring text or noise; candidate counts are not defect counts. Content far outside the inspected band and semantic context are not exhaustively detected.

`node tools/source-raster-coverage.mjs --output artifacts/source-raster-coverage/report.json --check` reconciles that snapshot with the complete live catalog-use universe, source/image hashes and source frames, then recomputes component-derived edge and aggregate counts. CI rejects omissions, unsupported repartition into unassessable cases, orphan frames and inconsistent metrics. It does not rerender the private PDFs or approve source semantics. Regenerate the offline snapshot when live source geometry changes; preserve earlier snapshots. The complete offline audit checks actual source windows; only the explicitly recorded crop replay sets have also been compared pixel for pixel with their published or proposed PNGs.

Word-box intersections can flag harmless OCR envelopes and miss damaged raster glyphs; source/pixel review remains necessary. Whole-book semantic price completeness, table completeness, field relevance and unknown continuations cannot currently be proved automatically. Their unresolved universe must remain inventoried and assigned for review. Do not repair a newly discovered systemic class before preserving its failing cases and capturing its complete exposed-data denominator.

Track user-reported findings and their before/after evidence in `research/source-viewer-dogfood-findings.json` and the binding-level ledgers. Layout and notice checks cover desktop/mobile rendering and keyboard operation where tested; geometric checks alone do not establish usability.
